# Washi

Downloads for **Washi**, a paper-collage web browser for the Mac.

**Install:** open the latest release below, download `Washi-<version>-arm64.dmg` (Apple silicon: M1 and newer) or `-x64.dmg` (Intel), open it and drag Washi into Applications.
The first time, macOS asks you to confirm: **System Settings → Privacy & Security → Open Anyway**.

After that, Washi updates itself.
